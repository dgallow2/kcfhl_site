
# Fantasy Hockey Tool — Phase 1a (Two-Team Trades, Full Rosters)

Contents:
- `rosters.json` — parsed from your current index.html (players, minor_pro, prospects, picks, waiver_claims: 5). "None" entries skipped.
- `transactions.json` — trade log (human + structured entries)
- `trade_tool.py` — Streamlit app to make **two-team trades**
- `.gitignore` — common ignores for Python/Streamlit projects

## Quick start

```bash
pip3 install streamlit
streamlit run trade_tool.py
```
